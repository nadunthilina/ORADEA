# 🍔 ORADEA - Food Delivery Platform

ORADEA is a full-stack food delivery application featuring a customer-facing frontend, an administrative dashboard, and a robust backend API.

## 🏗️ Project Structure

The repository is organized into three main applications:

- **/frontend**: The customer-facing web application built with **Next.js**, React, and TypeScript. Includes features like browsing products, cart management, and user profiles.
- **/admin**: The administrative dashboard built with **React** and **Vite** for managing orders, products, and users.
- **/backend**: The RESTful API built with **Node.js** and **Express**, providing data to both the frontend and admin panels.

## 🚀 Tech Stack

- **Frontend:** Next.js, React, TailwindCSS, TypeScript
- **Admin Panel:** React, Vite, TypeScript
- **Backend:** Node.js, Express, MongoDB (Mongoose)
